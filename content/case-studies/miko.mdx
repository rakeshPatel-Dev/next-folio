## What it does

- Saves the active page with its title, URL, domain, favicon, and timestamp.
- Groups saved links by Today, Yesterday, This week, and Earlier, so there are no folders to manage.
- Searches titles, URLs, and domains instantly as you type.
- Detects duplicates and points you to the link you already saved.
- Supports inline title editing, one-click delete, and a quick remove shortcut that can be undone from the page.
- Adds a context menu action that toggles between saving and removing the current page.
- Lets you customise the toast messages shown after saving or removing a link.

## Local first, always

Miko has no backend and no account system. Bookmarks live in IndexedDB inside the extension, settings live in `chrome.storage.local`, and nothing is sent to a server. That keeps the extension fast, private, and usable offline.

## Under the hood

Miko is built with WXT, React, TypeScript, and Tailwind CSS. A background service worker handles keyboard commands, context menus, and badge feedback, while the popup is a compact 420 × 540 interface with date-grouped bookmark pages. Storage is wrapped behind a small repository layer so the data model can evolve without leaking browser APIs into React components.
